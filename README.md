# Тестовое задание к стажировке ВКонтакте

**Тестовое задание: «Разговорные рекомендации музыки по пользовательскому интенту»**

**Цель**
Исследовать, какие семантические признаки музыкальных треков могут быть полезны для задач рекомендаций, и реализовать базовый пайплайн по автоматическому извлечению или предсказанию таких признаков. В результате у вас должен получиться небольшой датасет музыкальных треков, обогащённый различными характеристиками (жанр, настроение, контекст использования и т.д.), а также анализ того, какие признаки потенциально наиболее полезны для систем рекомендаций.

**Задание 1: Сбор датасета**
Соберите небольшой датасет музыкальных треков (50-100 треков).
Источники могут быть любыми открытыми:
* YouTube
* Spotify previews
* Kaggle
* Hugging Face datasets
* другие открытые источники

По каждому треку желательно собрать:
* название
* исполнитель
* ссылка на аудио или аудиофрагмент
* базовые метаданные (если доступны)

Опишите:
* какие источники данных использовались
* как отбирались треки
* какие жанры или категории включены в датасет
* какие ограничения по количеству треков на жанр или артиста вы использовали

**Задание 2: Формирование набора признаков**
Определите набор семантических признаков, которыми можно обогатить музыкальные треки.
Примеры возможных признаков:
* жанр
* настроение (energetic, calm, sad, happy и т.д.)
* темп / энергичность
* контекст использования (для работы, для тренировки, для вечеринки)
* атмосфера
* эпоха
* похожие артисты

Вы можете:
* извлекать признаки автоматически
* использовать предобученные модели
* использовать LLM
* использовать аудио-модели (например: CLAP, MusicLM-подобные модели, open audio embeddings)

Опишите:
* какие признаки вы выбрали
* почему именно они могут быть полезны для рекомендаций

**Задание 3: Извлечение признаков**
Реализуйте пайплайн для извлечения или предсказания выбранных признаков
Можно использовать:
* аудио-эмбеддинги
* аудио-классификационные модели
* LLM
* мультимодальные модели

Опишите:
* какие модели или библиотеки использовали
* почему был выбран именно этот подход
* какие альтернативы рассматривались

**Задание 4: Анализ данных (EDA)**
Проведите небольшой анализ получившегося датасета:
* распределение жанров
* распределение настроений
* распределение контекстов использования
* корреляции между признаками (если есть)

Постройте несколько визуализаций

**Задание 5: Эксперименты с представлением треков**
Используя извлечённые признаки или эмбеддинги:
* попробуйте построить простую модель похожести треков
* визуализируйте пространство эмбеддингов (UMAP / t-SNE)
* покажите примеры ближайших треков

Опишите:
* насколько полученные признаки отражают реальную похожесть музыки
* какие признаки оказались наиболее полезными

**Документация и Формат результата**
В ноутбуке должно быть подробно описано:
* как собирался датасет
* какие признаки были выбраны и почему
* какие модели использовались для извлечения признаков
* какие эксперименты были проведены
* какие выводы можно сделать для задач музыкальных рекомендаций
* какие ограничения и проблемы вы обнаружили

* код пайплайна
* markdown-описания каждого шага
* визуализации и графики
* описание полученных признаков
* выводы и анализ
