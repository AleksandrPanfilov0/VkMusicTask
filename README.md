# Тестовое задание к стажировке ВКонтакте

**Тестовое задание: «Разговорные рекомендации музыки по пользовательскому интенту»**[cite: 7]

**Цель**
Исследовать, какие семантические признаки музыкальных треков могут быть полезны для задач рекомендаций, и реализовать базовый пайплайн по автоматическому извлечению или предсказанию таких признаков[cite: 7]. В результате у вас должен получиться небольшой датасет музыкальных треков, обогащённый различными характеристиками (жанр, настроение, контекст использования и т.д.), а также анализ того, какие признаки потенциально наиболее полезны для систем рекомендаций[cite: 8].

**Задание 1: Сбор датасета**
Соберите небольшой датасет музыкальных треков (50-100 треков)[cite: 9].
Источники могут быть любыми открытыми:
* YouTube[cite: 9]
* Spotify previews[cite: 9]
* Kaggle[cite: 9]
* Hugging Face datasets[cite: 9]
* другие открытые источники[cite: 9]

По каждому треку желательно собрать:
* название[cite: 9]
* исполнитель[cite: 9]
* ссылка на аудио или аудиофрагмент[cite: 9]
* базовые метаданные (если доступны)[cite: 9]

Опишите:
* какие источники данных использовались[cite: 10]
* как отбирались треки[cite: 10]
* какие жанры или категории включены в датасет[cite: 10]
* какие ограничения по количеству треков на жанр или артиста вы использовали[cite: 10]

**Задание 2: Формирование набора признаков**
Определите набор семантических признаков, которыми можно обогатить музыкальные треки[cite: 11].
Примеры возможных признаков:
* жанр[cite: 11]
* настроение (energetic, calm, sad, happy и т.д.)[cite: 11]
* темп / энергичность[cite: 11]
* контекст использования (для работы, для тренировки, для вечеринки)[cite: 11]
* атмосфера[cite: 11]
* эпоха[cite: 11]
* похожие артисты[cite: 11]

Вы можете:
* извлекать признаки автоматически[cite: 11]
* использовать предобученные модели[cite: 11]
* использовать LLM[cite: 11]
* использовать аудио-модели (например: CLAP, MusicLM-подобные модели, open audio embeddings)[cite: 11]

Опишите:
* какие признаки вы выбрали[cite: 12]
* почему именно они могут быть полезны для рекомендаций[cite: 12]

**Задание 3: Извлечение признаков**
Реализуйте пайплайн для извлечения или предсказания выбранных признаков[cite: 13].
Можно использовать:
* аудио-эмбеддинги[cite: 13]
* аудио-классификационные модели[cite: 13]
* LLM[cite: 13]
* мультимодальные модели[cite: 13]

Опишите:
* какие модели или библиотеки использовали[cite: 13]
* почему был выбран именно этот подход[cite: 13]
* какие альтернативы рассматривались[cite: 13]

**Задание 4: Анализ данных (EDA)**
Проведите небольшой анализ получившегося датасета:
* распределение жанров[cite: 14]
* распределение настроений[cite: 14]
* распределение контекстов использования[cite: 14]
* корреляции между признаками (если есть)[cite: 14]

Постройте несколько визуализаций[cite: 14].

**Задание 5: Эксперименты с представлением треков**
Используя извлечённые признаки или эмбеддинги:
* попробуйте построить простую модель похожести треков[cite: 15]
* визуализируйте пространство эмбеддингов (UMAP / t-SNE)[cite: 15]
* покажите примеры ближайших треков[cite: 15]

Опишите:
* насколько полученные признаки отражают реальную похожесть музыки[cite: 15]
* какие признаки оказались наиболее полезными[cite: 15]

**Документация и Формат результата**
В ноутбуке должно быть подробно описано:
* как собирался датасет[cite: 16]
* какие признаки были выбраны и почему[cite: 16]
* какие модели использовались для извлечения признаков[cite: 16]
* какие эксперименты были проведены[cite: 16]
* какие выводы можно сделать для задач музыкальных рекомендаций[cite: 16]
